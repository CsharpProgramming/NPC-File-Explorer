# NPC File Explorer 1.4.0
The NPC File Explorer is a custom file explorer made using the C# Programming langugage. It supports all the basic features you need to browse and modify files.

## Program Goal / Why did I make this?
The development of the program started out because I was annoyed with not being able to see folder sizes inside my file explorer. I wanted to create my own one to be able to have it look just how I want it, and be able to add any features I want.

## Development Goals
Here are the big goals for development of the program. Therea are a couple of backend changes to make the program more capable and work better.
 - Improve search code speed,
 - Sidebar customization,
 - Light mode,
 - Integrate AI??

## Features
These are the features currently in the program:
 - Browse files and folders
 - Copy/Paste/Cut/Delete
 - Fast indexed search system
 - Custom functional sidebar
